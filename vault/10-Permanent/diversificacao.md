# Diversificação

Estratégia de distribuir investimentos entre diferentes classes de ativos, setores e geografias para reduzir o risco total do portfólio sem necessariamente reduzir o retorno esperado.

## Princípio fundamental
> "Não coloque todos os ovos na mesma cesta."

A diversificação funciona porque ativos diferentes reagem de formas diferentes aos mesmos eventos econômicos. Quando um cai, outro pode subir ou se manter estável.

## Níveis de diversificação

| Nível | Exemplo |
|---|---|
| **Por classe de ativo** | Renda fixa + renda variável + imóveis |
| **Por setor** | Tecnologia + saúde + energia + consumo |
| **Por geografia** | Brasil + EUA + Europa + emergentes |
| **Por prazo** | Curto + médio + longo prazo |
| **Por emissor** | Não concentrar em um único banco/empresa |

## Correlação
A chave da diversificação é escolher ativos com **baixa correlação** entre si. Dois ativos altamente correlacionados não oferecem diversificação real.

## Modelo de Markowitz
O **Investment Advisor** usa a otimização de Markowitz para encontrar a combinação de ativos que oferece o **máximo retorno para um dado nível de risco** (fronteira eficiente).

## Limites
- Diversificação excessiva dilui retornos (di-worse-ificação)
- Não protege contra risco sistêmico (crise global)
- Exige rebalanceamento periódico
