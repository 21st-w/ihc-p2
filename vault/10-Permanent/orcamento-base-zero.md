# Orçamento Base Zero

Metodologia onde cada real da renda mensal recebe uma função específica antes do mês começar. O saldo final planejado é sempre **zero** — não sobra dinheiro "livre", cada centavo tem destino.

## Como funciona
1. Listar toda a renda esperada do mês
2. Listar todas as despesas previstas por categoria
3. Alocar cada real até que: `Renda - Despesas - Poupança = 0`
4. Acompanhar execução vs planejado ao longo do mês

## Vantagens
- Elimina o "dinheiro perdido" — gasto sem categoria
- Força priorização consciente
- Funciona bem para renda irregular (freelancers)
- Cada mês é único — permite ajustar sazonalidades

## Desvantagens
- Exige mais tempo e disciplina que a regra 50/30/20
- Pode gerar fadiga de decisão
- Precisa de revisão se a renda é muito volátil

## Ferramentas de apoio
O FinTrack automatiza esse processo: o **Budget Advisor** usa programação linear para sugerir a alocação otimizada, respeitando restrições mínimas por categoria.
