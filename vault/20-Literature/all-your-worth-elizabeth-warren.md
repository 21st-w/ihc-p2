# All Your Worth — Elizabeth Warren

Livro que popularizou a [[regra-50-30-20]]. Warren argumenta que a chave para a estabilidade financeira não é cortar o café diário, mas garantir que a **estrutura** dos gastos esteja correta.

## Teses principais
1. Gastar menos é menos importante do que gastar **na proporção certa**
2. Necessidades acima de 50% da renda é sinal de problema estrutural (moradia cara demais, carro demais)
3. Poupança de 20% deve ser automática — "pay yourself first"
4. Desejos de 30% não são pecado — são necessários para sustentabilidade do orçamento

## Críticas
- Proporções podem não funcionar em contextos de renda muito baixa
- Não leva em conta dívidas com juros altos (que deveriam ter prioridade absoluta)
- Escrito para o contexto americano — adaptação necessária para Brasil

## Relevância para o FinTrack
O **Budget Advisor** usa esta regra como baseline default para sugestões de alocação, mas permite personalização via programação linear para se adaptar à realidade de cada usuário.
